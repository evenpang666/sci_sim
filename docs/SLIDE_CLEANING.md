# 清洗玻片与入干燥箱

环境 ID：`SciSim-SlideCleaning-v0`；CLI 任务名：`slide_cleaning`。使用现有双 UR7e + Robotiq 2F-85、柜式架台和四路 RGB-D。`--layout lab` 包含五桌十臂、二十路相机。

## 任务流程与判定

1. 左臂抓住玻片槽提杆，从桌面取起，放入透明烧杯并释放；检测槽底与杯底接触及槽体位于杯内。
2. 左臂夹持烧杯外侧夹持耳，将装有玻片槽的烧杯放入敞口超声清洗机并释放；检测杯底与清洗槽底接触、杯体直立且位于槽内。
3. 右臂接触绿色清洗按钮；仅在玻片槽、烧杯和预装水条件满足时开始计时。默认清洗 2 秒，可通过 `LabConfig.run_seconds` 修改。计时完成前取出载荷会失败。
4. 左臂取出烧杯，放在桌面前方的绿色暂存区域并释放，玻片槽仍须留在杯中。右臂再将整套载荷移到干燥箱右前方、门扇扫掠范围之外的桌面暂存位，为开门让出空间。
5. 右臂抓住干燥箱门把手，先拉开约 26°，松爪并换接触位置，再用指端从把手内侧推开门。推门阶段不夹持把手，门的转动由实际接触力驱动。
6. 右臂从正面以约 45° 斜向夹住烧杯夹持耳，将清洗后的烧杯连带玻片槽从正面送入箱内搁板并释放；杯底须接触搁板、杯槽仍保持嵌套并稳定。
7. 右臂关门。只有完成清洗与入箱、门关闭、杯槽嵌套且释放稳定 0.3 秒后才成功。

按新增要求，原流程末尾的“取出玻片槽”替换为整套入箱，玻片槽一直留在烧杯内。任务终点是入箱关门，不表示完成了真实干燥；本次没有加热启动、抽真空、倒水或干燥计时操作。

五片 25×75 mm 玻片固定在玻片槽中。烧杯和玻片槽是两个独立的自由动态刚体：搬运中依赖重力、杯底、杯壁和夹爪接触，不使用物体传送或固定抓取约束。规划时把杯和槽的碰撞几何共同计入载荷；每次放置前重新测量物体相对夹爪的偏移。

## 建模边界

- 外观参考用户提供的清洗和干燥箱 GIF，尺寸为任务级近似；超声槽为 280×280×180 mm，烧杯直径 90 mm、高 115 mm，干燥箱为 380×360×520 mm。模型为程序化几何，不是厂家 CAD。
- 烧杯和清洗机默认预装水。水面使用透明视觉几何，水的载荷由杯底附加质量近似；不求解流体流动、溢出、声场或化学清洁效果。玻片槽侧向移动允许实际杯壁间隙，不要求完全同心。
- 为适配 2F-85，烧杯外壁增加蓝色夹持耳，清洗按钮位于上沿。玻片槽自带提杆。当前不实现逐片取放、清洗机开关盖或不同清洗液的换液流程。
- 清洗场景及多桌总览默认使用支持透明材质的 `default` raster shader。四路深度仍是理想渲染深度，不代表真实相机穿透透明容器的测量能力。
- 干燥箱前门有真实竖直铰链、透明窗和外置夹持把手；为让出右臂入箱通道，采用左铰链、向左开门；柜体是开放内腔，搁板参与碰撞，托条外观覆盖连续承载面。没有温度、压力、水分或传热模型。
- 专家读取仿真物体位姿与接触信息。完整操作验证范围是 UR7e、种子 42 和 43；不是大规模成功率评测。

## 运行

在项目根目录激活仿真环境并准备机械臂资产。新清洗场景无需额外导入 AtomBridge 仪器，原三个场景和多桌总览仍需要原有资产。

```bash
source .venv/bin/activate
sci-sim demo --task slide_cleaning --seed 42
sci-sim view --task slide_cleaning --layout single
sci-sim render --task slide_cleaning --layout single --output outputs/slide_cleaning.png
sci-sim render --layout lab --output outputs/five_stations.png

python scripts/validate_expert.py --task slide_cleaning --seed 42 \
  --trace --output outputs/slide_drying/verified_42.json
python scripts/render_task_trace.py outputs/slide_drying/verified_42.pkl
SCI_SIM_INTEGRATION=1 pytest -q
```
