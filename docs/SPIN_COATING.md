# 旋涂与闪蒸场景

环境 `SciSim-SpinCoating-v0`，CLI 任务 `spin_coating`。按用户旋涂 GIF 构建透明翻盖、白蓝色机身和圆形内腔；尺寸为任务建模假设，不是厂家 CAD。单桌双 UR7e + Robotiq 2F-85，四路 RGB-D。`--layout lab` 将五个场景并排放置，共十臂、二十路相机。

## 十二步流程及判据

1. 右臂抓盖把手，沿真实铰链打开；角度小于 −1.25 rad。
2. 左臂从支座取 25×25×2 mm 正方形玻片（边长为当前建模假设），放在中央托盘上。要求水平、位置误差小于 12 mm、与托盘接触并释放。
3. 左臂从架上取移液器；针尖进入烧杯液面下，保持直立且连续停留 0.5 s 后吸入一份液体。
4. 针尖位于玻片中心 7 mm 内、上方 15–45 mm，连续停留 0.4 s 后释放一滴。整个回合只转移一次；未吸液不能滴液。
5. 移液器放回架上并释放、稳定，与架接触；必须在盖仍打开时完成此步骤。
6. 右臂关闭盖子，角度大于 −0.07 rad。
7. 右臂接触绿色启动按钮。只有玻片就位、滴液完成、移液器归架且盖关闭时才能启动；运行时盖打开或耗材失位立即失败。只有测得托盘实际旋转时才累计运行时长，默认 2 s。

8. 等待托盘电机停转、玻片稳定，右臂重新打开旋涂仪盖。
9. 右臂打开同桌右侧闪蒸仪盖，角度小于 −1.25 rad。
10. 右臂抓取同一片涂覆后的正方形玻片，转移至闪蒸托盘中心并释放；中心 XY 误差小于 18 mm、接触托盘且稳定。
11. 右臂关闭闪蒸盖，角度大于 −0.07 rad。
12. 右臂接触闪蒸仪自己的绿色启动按钮。要求先完成旋涂与转移、玻片就位、移液器已归架、闪蒸盖关闭且托盘停转。运行时破坏互锁即失败，默认 `flash_seconds=2.0`；稳定完成后整个回合才成功。运行指示灯为琥珀色。

闪蒸仪与旋涂仪共用第五张桌子、双臂和四路相机。闪蒸仪按 GIF 近似构建蓝色机身、金属多孔托盘外观和带圆形观察窗的翻盖，外廓 280×280×190 mm 为建模假设。默认控制步数上限提高到 8000。

开盖、抓取、放置、关盖使用 MPlib 规划和物理接触；动态玻片和移液器不使用位姿重置或固定抓取约束。旋转由真实托盘关节电机驱动，玻片通过摩擦随动。专家可访问仿真真实位姿和接触信息。

## 建模边界

- 默认烧杯已有褐色液体，烧杯固定在桌面。移液器和玻片是独立动态刚体。
- 没有独立拇指/移液器柱塞动作；采用针尖位置和停留时间触发吸液与滴液的单剂量模型。液体、单滴和涂层仅为视觉标记，不参与碰撞、不求解流体、膜厚或化学过程。
- 旋转速度为 6 rad/s 的低速演示，不代表真实工艺转速。没有真空吸附模型。
- 玻片初始支座和中央托盘均抬高，为平行夹爪留下夹持空间；移液器使用简化几何和支架。
- 闪蒸是溶剂快速挥发的计时抽象，不模拟真空压力、传热、溶剂挥发或结晶，也不模拟光学闪光。托盘孔为视觉细节，承载碰撞面连续；玻片仍依赖真实接触支撑。
- 透明材质使用 `default` raster shader，深度为理想渲染结果。

## 复现

```bash
sci-sim demo --task spin_coating --seed 42
python scripts/validate_expert.py --task spin_coating --seed 42 --trace \
  --output outputs/spin_flash/verified_42.json
python scripts/render_task_trace.py outputs/spin_flash/verified_42.pkl
```

验证输出 JSON 包含阶段、最终事实、任务状态和失败详情；PKL 为实际物理状态快照，MP4 从这些快照渲染。只加载可信本地 PKL。
